# halflings

Браузерная 3D-игра: прогулка по деревне полуросликов. Небольшая долина,
норы в холмах, бытовые занятия жителей. Ни боёвки, ни инвентаря.

Цель — витрина навыков в 3D-вебе. Приоритет у картинки и плавности,
а не у объёма контента.

## Стек

Vite + TypeScript (строгий режим), three.js без обёрток,
`three-mesh-bvh` для коллизий по террейну. Бэкенда нет,
всё раздаётся статикой.

## Ассеты

Персонажи и анимации — [KayKit](https://kaylousberg.com) от Kay Lousberg,
лицензия CC0. Исходные паки в репозиторий не входят: нужные файлы
скопированы в `assets/`.

Файлы анимаций везут внутри меш-манекен, которому в игре делать нечего.
Он вырезается инструментом без зависимостей — 4.34 МБ превращаются
в 2.45 МБ, по сети под brotli 1.31 МБ в 790 КБ:

```bash
node tools/strip-anim-meshes.mjs
```

Инструменту нужны распакованные паки в корне проекта.

## Про имена

Проект вдохновлён Широм Толкина, но имена из легендариума защищены
товарными знаками и в репозитории не используются. Вместо них —
нейтральные `halfling`, `village`, `valley`, `river`.
