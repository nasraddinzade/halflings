# Промты для Claude Code

Давать по одному, в порядке. Следующий — только когда предыдущий принят.

---

## 0. Инвентаризация ассетов

> Прочитай CLAUDE.md. Изучи рекурсивно содержимое папок
> `KayKit_Adventurers_2.0_FREE/` и `KayKit_Character_Animations_1.1/`.
> Составь `docs/ASSETS.md`, в нём:
> 1) какие персонажи есть в паке Adventurers, из каких мешей состоит
>    каждый и сколько в них треугольников;
> 2) какие файлы анимаций относятся к `Rig_Medium`, какие клипы лежат
>    внутри каждого — точные имена и длительность в секундах;
> 3) где лежат текстуры-атласы и какого они разрешения;
> 4) совпадают ли имена костей между персонажами пака и файлами анимаций.
>
> Для чтения gltf/glb напиши временный скрипт, не гадай по именам файлов.
> Код игры пока не пиши.

Проверить: имена клипов реальные, персонажей пять, кости совпадают.

---

## 1. Вертикальный срез

> Собери вертикальный срез. Vite + TypeScript + three.js.
> Heightmap-террейн с холмами, коллизии через three-mesh-bvh.
> Контроллер персонажа от третьего лица: ходьба, бег, стамина, прыжок.
> Загружай `assets/characters/halfling_base.glb` с масштабом
> `CHARACTER_SCALE` и клипы анимаций по именам из `docs/ASSETS.md`.
> Материалы серые, без стилизации, без UI, без звука.
> Сначала покажи структуру файлов и план — код после подтверждения.

Критерий готовности: **бегать приятно**. Если управление вязкое или
камера дёргается — доводить здесь, дальше не идти.

---

## 2. Отладочная панель

> Добавь отладочную панель: FPS, число draw calls, количество
> треугольников в кадре, текущий клип анимации, скорость персонажа,
> стамина. Отдельным модулем, отключаемым одной константой.

Draw calls — метрика, по которой станет видно, когда пора склеивать
меши персонажа.

---

## 3. Стилизация

> Реализуй визуальный слой: toon-шейдер с 2–3 ступенями освещения,
> обводка методом inverted hull, туман с цветом из палитры,
> палитра проекта в `config/palette.ts`. Все материалы сцены проходят
> через общую функцию, задающую стиль — ни один ассет не приносит
> свои цвета.

Здесь останавливаемся и смотрим кадр. Если картинка не нравится —
проблема в арт-дирекшне, и её не закроет количество ассетов.

---

## 4. Система жителей

> Реализуй сборку NPC из конфига по описанию в CLAUDE.md.
> Части берутся из разных персонажей пака, склеиваются в один
> `SkinnedMesh`, цвет задаётся сдвигом UV по атласу.
> Конфиг выводится детерминированно из seed.
> Добавь сцену-стенд: 20 сгенерированных жителей в ряд.

---

## 5. Занятия

> Подключи анимации инструментов к ролям NPC: gardener копает,
> miller пилит, fisher рыбачит. Простой конечный автомат состояний
> с переходами idle → move → work → idle. Точки работы задаются
> данными, не кодом.

---

## 6. Оптимизация

> Прогони ассеты через Draco или Meshopt, добавь LOD для персонажей,
> инстансинг для растительности, отсечение по расстоянию.
> Цель: 60 fps на среднем ноутбуке при 30 видимых NPC.
